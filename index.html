First-Class Shape-Aware Tensors

Tensors are native language primitives with static rank and dimension inference. Shape mismatches are detected at compile time rather than crashing in production.

let input = Tensor::from_data([1, 4], [0.5, -0.2, 0.8, 1.2]);
let layer = DenseLayer::new(4, 2);
let output = layer.forward(&input); // Verified at compile-time
⚡

Unified `@gpu` Tile Kernels

Compile identical code directly to SPIR-V, Vulkan, and CUDA cooperative matrix targets without switching languages or runtime wrappers.

@gpu
fn matmul(a: &Tile<f32, 16>, b: &Tile<f32, 16>) {
    tile_matmul(a, b);
}
🛡️

Deterministic Memory Safety

Zero garbage collection pauses. Agam combines affine types, static escape analysis, and explicit linear ownership for predictable latency.

Zero-GC Linear Types No Use-After-Free
🎨

Agent-to-User Protocol (A2UI)

Declarative reactive UI protocol natively embedded in the compiler. Synthesize and stream live Bento-box interfaces directly from autonomous agent pipelines.

Reactive VDOM Stream Protocol
🪄

Algebraic Effects & Resumable Handlers

Decouple computational logic from environmental side-effects. Handle async I/O, error recovery, and transactional states cleanly without colored functions.

effect Console { fn log(msg: string) -> (); }
handle compute() with Console {
    fn log(msg, resume) { println(msg); resume(()) }
}
