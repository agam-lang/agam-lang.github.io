Design Philosophy

What is Agam?

A unified language designed to solve the critical friction in modern artificial intelligence and systems engineering.

⚡

The Two-Language Problem

For over a decade, artificial intelligence and high-performance computing have lived with an unsustainable compromise: engineers write high-level prototypes in Python, but must rewrite performance-critical layers in C++, CUDA, or Triton. This fragmentation leads to memory leaks, deployment friction, opaque GPU driver crashes, and huge glue overhead.

🎯

Agam's Architectural Answer

Agam eliminates the divide. It gives developers high-level ergonomic syntax with compile-time tensor shape proofs, native automatic differentiation, and direct LLVM / SPIR-V machine code compilation. You write clean, readable code that runs directly on bare-metal hardware with predictable microsecond latency.

🛡️

Predictable Determinism

No garbage collection pauses, no hidden reference-counting stalls, and no unexpected runtime aborts. Agam combines affine type checking, static escape analysis, and explicit linear ownership so your autonomous agents and embedded models execute with mathematical guarantees.

First-Class Shape-Aware Tensors

Tensors are native language primitives with static rank and dimension inference. Shape mismatches are caught during compilation rather than crashing in production.

let input = Tensor::from_data([1, 4], [0.5, -0.2, 0.8, 1.2]);

Getting Started with Agam

Agam distributes as a single standalone executable toolchain. You can install it using Cargo directly from the official repository: 

# 1. Install Agam compiler from source
cargo install --git https://github.com/agam-lang/agam.git

# 2. Verify installation
agam --version
# Output: agam v0.1.0-alpha (target: x86_64-pc-windows-msvc)

Creating Your First Project

Use the built-in package manager to scaffold a new systems or AI project:

# Initialize a new application
agam new my_neural_app
cd my_neural_app

# Project structure:
# ├── Agam.toml     (Package manifest & dependencies)
# └── src/
#     └── main.agam  (Application entrypoint)

Building and Running

# Fast development check (parses & typechecks without full LLVM emission)
agam check

# Compile and run immediately with JIT
agam run

# Produce optimized bare-metal production binary with LLVM -O3
agam build --release

Core Language Syntax & Semantics

Agam uses clean, modern systems syntax. Variables are immutable by default, memory is tracked linearly, and errors are handled explicitly.

Variables and Mutability

fn main() {
    let message = "Immutable string binding";
    let mut counter: i32 = 0;
    counter = counter + 1;
    
    // Explicit type casts using `as`
    let float_val = counter as f64 * 3.14159;
}

Structs, Enums, and Pattern Matching

struct DeviceConfig {
    device_id: u32,
    enable_tensor_cores: bool,
}

enum HardwareTarget {
    HostCPU,
    VulkanGPU(DeviceConfig),
    CudaCooperative(u32),
}

fn dispatch_target(target: HardwareTarget) {
    match target {
        HardwareTarget::HostCPU => println("Targeting host CPU SIMD"),
        HardwareTarget::VulkanGPU(cfg) => println("Targeting Vulkan device {}", cfg.device_id),
        HardwareTarget::CudaCooperative(sm) => println("Targeting CUDA SM {}", sm),
    }
}

Tensors, Autodiff & Hardware Acceleration

Unlike general-purpose languages where tensors are third-party wrappers, Agam features native dimensional semantics.

Compile-Time Shape Verification

import std::tensor::Tensor;
import std::ml::DenseLayer;

fn train_step() {
    // Tensor with shape [1, 4] verified statically
    let input = Tensor::from_data([1, 4], [0.5, -0.2, 0.8, 1.2]);
    
    // Dense layer mapping [4] -> [2]
    let layer = DenseLayer::new(4, 2);
    
    // Output is proven to be shape [1, 2] at compile-time
    let output = layer.forward(&input);
    println("Output Shape: {:?}", output.shape());
}

Multi-Vendor GPU Kernels

The @gpu decorator signals the compiler to lower the designated function to SPIR-V / Vulkan cooperative matrix operations without runtime wrappers.

@gpu
fn tile_gemm(a: &Tile, b: &Tile, c: &mut Tile) {
    tile_matmul(a, b, c);
}
